# Odin Hates Litter

A Valheim mod by Dova. Leave rubbish behind and Odin will give you something to clean up.

At 100 wrath, Odin summons litter and a bin. You have two minutes to clean up before enemies arrive. Finish the event for coins, materials, Epic Loot gear and a stamina blessing. Ocean events send serpents after you instead.

Build a **Litter Bin** under **Hammer > Misc**, add the offering, then press **Alt + E** to start a trial. Friends can join and earn their own rewards.

Events last up to ten minutes. The dome keeps players and enemies inside, with three returns after death by default. Progress is saved when you leave; timers pause while the world is offline.

## Install

Download **OdinHatesLitter.zip** from [Releases](https://github.com/VariantCreator/OdinHatesLitter/releases/latest).

Requires **BepInExPack Valheim**, **Jotunn 2.30.1+** and **Epic Loot 0.14.10+**. Install the same version on the server and every client. For manual installation, copy the ZIP's `plugins` folder into `BepInEx`, then restart. Keep only one copy of `OdinHatesLitter.dll`.

## Settings

Use Configuration Manager (**F1**) or edit `BepInEx/config/Dova.OdinHatesLitter.cfg`. Server settings sync automatically; only admins and the host can change them.

Admins can open a bin to change its own range, litter placement and access settings.

# Odin Hates Litter

Odin's wrath, cleanup trials and raids for Valheim. By Dova.

## Features

- Littering builds wrath and triggers cleanup challenges or enemy attacks.
- Buildable Litter Bins and biome altars for starting events.
- New land altars check their full starting event area for dry ground, lava and uneven terrain. Existing altars stay in place.
- Enemy waves, mini-bosses and boss raids with phases and reinforcements.
- Ocean battles, craftable Sea Offerings and floating loot.
- Ocean altar docks sink during combat after a warning, then rise when the event ends.
- Personal completion rewards, guaranteed combat equipment rolls in presets, and 10-25 minute stamina, health and Eitr blessings.
- Event music, weather, boundaries and limited returns after death.
- Litter Bin icons above event enemies, with a boss icon beside them for bosses and mini-bosses.
- Saved event progress and starting settings. Cooldowns start after events end; replacing a player bin does not reset them.
- Automatic recovery for stranded enemies, with admin map markers and controls to return them to the arena.
- Personal contribution targets, reward cooldown warnings and credit for blocking event attacks.
- A journal of discovered altars with difficulty, readiness, cooldowns and your last result.
- Optional heavy, cursed and bonus litter, with limits on extra enemies and coins.
- Small spawn batches and a shared server limit for living event enemies.
- Six difficulty presets, from Relaxed to Cataclysm, with shark and serpent choices for Ocean events.
- Admin settings with Apply, Discard and Undo, plus separate controls for each event type, altar and bin.
- Separate HUD controls for every mode and altar type, notices that stay clear of the tracker, and personal results.
- Optional equipment bad-luck protection and saved reward history.

Use a Litter Bin with **Alt + E**, then press again to confirm. Sea Offerings use the same two-step confirmation at sea.

Open the altar journal from **F1 > General and display**, or use `odin_journal` in the console. Admins can inspect active events from **F1 > Admin and server > Event management**.

## Compatible mods

Epic Loot, Creature Level and Loot Control, Therzie's Monstrum, World Advancement Progression, Wacky Epic MMO System and Resurrection.

Also supports Venture Floating Items, Venture Location Reset, Upgrade World, Configuration Manager, Variant Announcements, ServerGuard and Discord Connector.

Epic Loot is required. The other integrations are optional.

## Requirements

**BepInExPack Valheim 5.4.2351+**, **Jotunn 2.30.1+** and **Epic Loot 0.14.10+**. The same mod build is required on the server and every client.
